# Public IPv4 addresses that scripts/scan-public-repo.mjs (pnpm scan:public) accepts, one per line:
#
#   <address>  # reason
#
# Each entry is a reviewed false positive, such as a well-known public address a doc has to name, and needs the lead
# maintainer's review before it lands. A server's own address never goes here: it never enters this repository.
# Tests and docs use the documentation ranges instead (192.0.2.x, 198.51.100.x, 203.0.113.x), which the scan ignores.
